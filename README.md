## 🌍WHO-HEALTH-STATISTICS🌍 ##

## 📌 Project Overview 📌 ##
This project is a comprehensive multi-sheet Excel dashboard built to analyse and track global health indicators, life expectancy, and demographic trends from 2000 to 2024. It serves as a professional portfolio demonstration of advanced data structuring, cleaning, and analytical modelling

## 🗂️ The 5-Sheet Project Structure 🗂️ ##
1. Raw Data Sheet
2. Analytical Road Map Sheet
3. Analysis / Pivot Table Sheet
4. Dashboard Sheet
5. Overview Sheet

## 📐 Formulas & Functions Covered 📐 ##
 **Lookup & Reference: `XLOOKUP`, `VLOOKUP`, `INDEX`, and `MATCH` for dynamic data retrieval**
 **Conditional Logic: Nested `IF` statements and `IFS` for multi-condition evaluations**
 **Aggregations: `SUMIFS`, `AVERAGEIFS`, `COUNTIF`, and `COUNTA` for targeted metric calculations**
 **Data Validation & Error Handling: Used to maintain data integrity and clean visual outputs across all sheets**
 
 ## 🎯 Topics & Analyses Covered 🎯  ##
 **Trend Analysis & Time-Series Analysis: Evaluating chronological progressions and long-term health indicator trajectories**
 **Pandemic Impact: Assessing health metrics during global crisis periods**
 **SDG Alignment: Tracking metrics tied to international sustainable development goals**
 **Data Audit & Quality:** Performing structured data checks and validation.
**Regional Breakdown & Regional-Aggregation: Analysing and grouping performance metrics across distinct WHO geographic regions.**
**Category-Breakdown: Segmenting datasets into core analytical categories**
