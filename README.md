# WHO Health Statistics Analytics & Monitoring Dashboard
A professional data analytics and monitoring dashboard built to track global health indicators, regional breakdowns, and time-series trends.
## PROJECT OVERVIEW ##
**Focus Areas: Reproductive, Maternal, Newborn, & Child Health (RMNCH) & Life Expectancy**
**Key Metrics: Tracking Global Percentage Changes, Absolute Point Variations, & Pandemic Impacts (2000-2030)**
**Features: Dynamic Lookups, Data Audit Validation, Pivot-Table Aggregations, & Visual Overview Layouts**
